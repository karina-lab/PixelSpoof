# PixelSpoof

## Description
An LSPosed that lets you spoof all device-specific properties of your device, selectively for individual apps, to a high end Pixel device. 
Currently Pixel 10 Pro XL (mustang).

## Installation
1. Install the APK.
2. Enable the **PixelSpoof** module in **LSPosed Manager**.
3. Select the apps in module's scope.
4. Restart the selected apps.

## Features
* Build.prop values from latest Pixel 10 Pro XL official firmware.
* Features xmls from Pixel 10 series.
